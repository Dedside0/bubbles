# Лопни пузыри

Простая игра на **Tkinter** — учебное задание для университета.

Пузыри поднимаются снизу вверх, их нужно ловить и лопать кликом мыши. За каждый лопнутый пузырь увеличивается счёт, который отображается в верхней части окна.

## Как запустить

### Требования

- Python 3.x
- [Pillow](https://pypi.org/project/Pillow/) — для загрузки и масштабирования изображения пузыря

### Установка зависимостей

```bash
pip install pillow
```

### Запуск

```bash
python main.py
```

Откроется окно размером 1600×800. Пузыри появляются с интервалом 300 мс и движутся вверх; пузыри, ушедшие за верхнюю границу, удаляются со сцены.

## Управление

- **Левая кнопка мыши по пузырю** — лопнуть пузырь и увеличить счёт.

## Структура проекта

| Файл | Описание |
| --- | --- |
| `main.py` | Логика игры: окно, холст, создание и движение пузырей, обработка кликов, счёт |
| `bbl.png` | Изображение пузыря |
| `pop.wav`, `pop2.wav` | Звуковые файлы (ресурсы проекта) |

## Что здесь демонстрируется

- создание окна и виджетов Tkinter (`Tk`, `Canvas`, `Label`);
- загрузка и масштабирование изображений через `PIL`;
- анимация с помощью `win.after()`;
- обработка событий мыши через `tag_bind()`;
- работа со словарём для хранения объектов на холсте.
